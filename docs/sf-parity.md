## Result and limits

The full workspace is copied into `src/02-work.html`, `src/sf.css` and one closure in `src/sf.js`. The old workspace markup, script closure and styles are removed. No iframe, remote image, extra theme switch or sample-local attention state machine remains. The build generates `ui-handbook.html`.

**One acceptance conflict remains:** the prototype retires the timeline to zero height with pointer events disabled while chat is focused. A natural frame click during that state is therefore impossible. The source frame-click focus-preservation guard is retained and reviewed, but is not reported as naturally tested with chat open. The port preserves retirement (decisions 1 and 6; rule 9). The caller should clarify that acceptance clause instead of accepting a synthetic event as a real click.

**Decision 1 exception:** `pushChat` adds incremental display of the copied mock reply because acceptance explicitly requires a streamed reply, while v5 appends the whole reply at once. The source message content and send branches are retained. This is a narrow, additive departure from copying unchanged function bodies; the task authorizes choosing the stated purpose where settled instructions conflict. No other decision departure. Required adaptations include token art, shared UX hit geometry/lock, held chat focus, one sliding selector indicator, no hover movement, fades, pointer/touch input, phone context sheet and local close controls. The source mock replies arrive whole; the copied reply path streams them to satisfy the explicit acceptance flow. Fit/zoom buttons provide a touch/keyboard equivalent to modifier-wheel. Picture tokens are complete background stacks; absent picture tokens use other theme tokens as fallbacks.

Hardware touch, non-Chromium engines and a live AI/video backend were not tested. Chromium touch pan/drag used six timed native touch moves, not a zero-duration synthetic drag. The v5 source supplies mock chat and preview art, not real generation or video playback. External fonts were blocked consistently for before/after browser checks. Bounded implementation observations are not statistical or universal compliance claims.

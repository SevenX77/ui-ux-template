# UI 视觉与交互规则 · v0.5

目的：让使用者在熟悉、克制且有层次的界面中专注内容，按需进入独立功能模块，并跨项目复用同一套视觉与交互语言。

[可交互规范册](ui-handbook.html)提供主样张、详细参考分析、场景库与统一数值表。完整显隐与注意力流程由新增主工作区示范；场景库保留原有功能并统一表面。颜色、圆角、间距、投影、动效及材质参数从 `design-tokens` 取值，属于本版采用值。

1. **按任务组织独立模块。** 阅读、数据、属性、Timeline 与 Agent 各有职责和状态；通过对齐、位置和显隐协作。让主要内容获得空间，必要工具靠近对象出现，避免用永久外框包住所有功能。
2. **用疏密分配注意。** 大图、趋势与主任务宽松，标签、字段、金额与状态紧密。主卡和小卡可不等宽，以有限间距角色组织组内与组间关系；选择和悬停不改变无关卡片列数。
3. **中性平面承载常态。** 使用 Neutral 方向的亮暗角色及成对前景，主动作黑白反转。蓝色用于有限强调，语义色配文字或图形。少数重点采用 Fintech 的柔光体积，以 CSS 多层渐变、内阴影和边缘高光实现，由统一变量控制。色相预览可实时换色、恢复默认，不改变平面语义色；与平面共享字体、对齐和间距。
4. **形状与深度按用途取档。** 控件、卡片／菜单、宽输入／大浮层分别使用对应圆角；胶囊和拼接边另有角色。普通卡片无描边、极淡阴影，hover 明显浮起；结构分组用单线，字段、端口、拖放与键盘焦点保留必要边界。
5. **保持 Agent 的三步关系。** 空待机只显淡 placeholder，无边框阴影；hover 浮起但不显历史；组件内 focus 立即扩展输入并在上方覆盖历史，同时让冲突 Timeline 隐藏且 inert。未保持展开时，离开后恢复 Timeline；显式保持可延续工作态，关闭时收回。保留未发送文字、选择与位置。
6. **明确活动归属。** 仅同工作区的相关模块随活动对象降低显著性，仍可点击切换意图。菜单、历史和子浮层属于父模块，移入它们保持活动。持续焦点与展开操作优先于偶然悬停；规范册其他区域不一起变淡。
7. **分别处理选择、编辑和展开。** 关闭工具保留对象选择；即时编辑更新本地对象，需要保存的编辑保留草稿，保存才提交，明确放弃才清除。恢复视图只改呈现；取消、撤销和重置说明各自影响。
8. **提供等价操作路径。** 键盘与触控能进入悬停所提供的必要工具，焦点可见且隐藏区域不可达。拖动配置有字段、按钮或键盘替代；菜单可关闭并回到入口，错误指出对象和修正方法，长内容与底部动作始终可达。
9. **动效交代变化。** 悬停延迟和动画时长分开，按反馈、浮层、抬升、模块进退及输入扩展取档。快速切换服从最新意图，通知不挤正文或抢焦点；回放显式启动且可暂停，减少动态效果仍保留结果和操作。
10. **按真实路径核验。** 检查明暗、窄屏、材质换色、主工作区 Agent 往返与 Timeline 菜单；场景库按各自说明核验原有操作及表面一致性。图表说明对象、单位、周期和类别。所有业务为本地模拟，页面内保留不承诺刷新后持久保存；视觉满意度由使用者判断。

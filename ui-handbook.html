02 / SCHEMES

主题

三对明暗，结构完全相同，只换变量。点一张卡片就能切换，整页跟着变。

换主题只改一个文件

主题是 src/themes.json 里的一条数据。构建时自动生成样式和切换器，组件代码一行不用动。不做"黑底钴蓝"：暗色要酷，商务蓝不符合。新项目先选一对，界面的明暗开关在这一对之内切换。

新增一个主题，要写的就是这些
{ "id": "ember", "pair": "paper", "mode": "dark", "name": { "zh": "余烬", "en": "Ember" }, "tokens": { "ground": "#0e0d0c", "ink": "#f1ece4", "signal": "#f1ece4", "c1": "#e8833a", … } }
三种破例 底永远是中性灰阶，只有这三种东西能有颜色或质感
